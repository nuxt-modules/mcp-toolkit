## Connect to the HTTP endpoint

Start Nuxt and connect to `http://localhost:3000/mcp` using Streamable HTTP. Use the exact route when a named server or custom route is configured. The toolkit serves modern and legacy protocol paths by default; host support for prompts, resources, OAuth, and interactive input still varies.

## Configure Cursor

```json [.cursor/mcp.json]
{
  "mcpServers": {
    "example": { "url": "http://localhost:3000/mcp" }
  }
}
```

Cursor supports project and user MCP configurations. Follow the [Cursor MCP documentation](https://cursor.com/docs/mcp) for current UI and OAuth behavior.

## Configure VS Code

```json [.vscode/mcp.json]
{
  "servers": {
    "example": { "type": "http", "url": "http://localhost:3000/mcp" }
  }
}
```

Follow the [VS Code MCP guide](https://code.visualstudio.com/docs/agent-customization/mcp-servers) for configuration scope, trust, secret inputs, and authentication prompts. Do not copy a real token into a committed project configuration.

## Configure authentication

For OAuth, enable the provider and endpoint [resource-server configuration](/getting-started/oauth). A compatible client discovers the authorization server from the 401 challenge and protected-resource metadata.

For static service credentials, configure the client's HTTP headers to send `Authorization: Bearer <token>`. Store that credential using the client's secret or environment mechanism. Do not publish it in an installation link, badge, or README.

## Limit the selected tools

A client can send `X-MCP-Tools` with comma-separated advertised tool names. Unknown names return HTTP 400; omitting the header selects the full tool catalog. It narrows tools only and never grants access or bypasses scope checks.

## Publish installation buttons

The module registers the install component when auto-imports are enabled:

```vue [app/components/McpInstall.vue]
<template>
  <InstallButton url="https://example.com/mcp" />
  <InstallButton url="https://example.com/mcp" ide="vscode" label="Add to VS Code" />
</template>
```

| Prop | Default | Meaning |
| --- | --- | --- |
| `url` | required | MCP endpoint URL |
| `ide` | `cursor` | `cursor` or `vscode` |
| `label` | IDE label | Button text |
| `showIcon` | `true` | Show the IDE icon |

The component links to `<url>/deeplink?ide=...`. Generated badge/deeplink routes exist under the module's top-level base route; manually composed routes do not automatically receive those companion routes.

## Add a README badge

```md [README.md]
[![Install MCP in Cursor](https://example.com/mcp/badge.svg)](https://example.com/mcp/deeplink)
[![Install MCP in VS Code](https://example.com/mcp/badge.svg?ide=vscode)](https://example.com/mcp/deeplink?ide=vscode)
```

Badge queries support `label`, `color`, `textColor`, `borderColor`, `icon=false`, and `ide=vscode`. Use hex colors without `#` and URL-encode custom labels. These routes are presentation helpers, not authentication mechanisms.
