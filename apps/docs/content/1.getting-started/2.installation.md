## Check your host

Use Nuxt **4.6 or later** with a Nitro server builder. Choose a Node version supported by your installed Nuxt release; this branch is validated locally on Node 24. Static generation alone cannot host an MCP endpoint.

## Install the beta explicitly

```sh [Terminal]
pnpm add @nuxtjs/mcp-toolkit@beta zod
```

The `beta` tag is populated by the reviewed release workflow. Before the first beta is published, use the exact preview installation command from the relevant PR's package-preview check. The stable package remains on `latest`; a normal unversioned install can select the 0.x API.

Zod 4 is used in the examples. Definitions accept supported Standard Schema libraries, so Zod is an application choice.

## Register the module

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@nuxtjs/mcp-toolkit'],
  mcp: { name: 'Example MCP', websiteUrl: 'https://example.com/docs/mcp' },
})
```

## Add a typed tool

```ts [server/mcp/tools/greet.ts]
import { z } from 'zod'
import { defineMcpTool } from '@nuxtjs/mcp-toolkit/server'

export default defineMcpTool({
  description: 'Greet someone by name',
  annotations: { readOnlyHint: true, openWorldHint: false },
  inputSchema: z.object({ name: z.string().min(1) }),
  outputSchema: z.object({ greeting: z.string() }),
  handler: ({ name }) => ({ greeting: `Hello ${name}!` }),
})
```

The default layout is:

```text [Project structure]
server/
  mcp/
    tools/greet.ts
    resources/
    prompts/
```

No handler file is needed under `server/mcp`. A default export in a definition directory is discovered automatically. A tool with no arguments omits `inputSchema` entirely.

## Prepare types and run Nuxt

```sh [Terminal]
pnpm exec nuxt prepare
pnpm exec nuxt dev
```

Open the MCP Inspector in Nuxt DevTools, choose Streamable HTTP, and connect to `http://localhost:3000/mcp`. List tools, then call `greet` with `{ "name": "Ada" }`. See [the inspector guide](/getting-started/inspector) for authentication headers.

Use [connection options](/getting-started/connection) for your client. Production deployments should configure [OAuth](/getting-started/oauth) or another endpoint authentication mechanism before exposing private data.
