## Give each endpoint a catalog

Configure servers in `nuxt.config.ts`. Each instance discovers only its configured directories and mounts a shared runtime handler. A file under `server/mcp` is a definition, not an endpoint configuration file.

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@nuxtjs/mcp-toolkit'],
  mcp: {
    servers: {
      default: { dir: 'mcp' },
      admin: {
        dir: 'mcp-admin',
        auth: { tokens: [process.env.MCP_ADMIN_TOKEN!] },
      },
    },
  },
})
```

This creates `/mcp` and `/mcp/admin`. The public catalog never discovers files in `server/mcp-admin`. Authentication is independent for each endpoint.

## Choose configuration or composition

| Approach | Use |
| --- | --- |
| `mcp.servers` | File discovery, Nuxt layers, JSON-serializable endpoint options |
| `createMcpHandler()` in a route | Explicit definition arrays, live callbacks, custom verifiers |

The beta removes `defineMcpHandler` files, handler attribution, and orphan filtering. Move old endpoint configuration into `mcp.servers`, or export a composed handler from an ordinary Nuxt route.
