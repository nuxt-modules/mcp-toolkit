## Configure discovered servers

`mcp.servers` entries support identity, route, directory roots, protocol era, legacy sessions, origins, request limits, and endpoint authentication. See the [configuration reference](/getting-started/configuration).

All options passed through discovery become generated code, so they must be serializable. Static `auth.tokens` and JWT `oauth` setup are supported; a live `auth.validate` callback belongs in a manual route.

Put live extension plugins in `<dir>/plugins.ts`, default-exported through `defineMcpPlugins`.



Use the installed engine's `ExtensionPlugin` contract when implementing an extension. Plugins are functions, so a `plugins` array in `nuxt.config.ts` is not the discovery API. Ambiguous plugin files in a root are rejected.

## Compose a handler directly

```ts [server/routes/private-mcp.ts]
import { z } from 'zod'
import { createMcpHandler, defineMcpTool } from '@nuxtjs/mcp-toolkit/server'

const greet = defineMcpTool({
  name: 'greet',
  inputSchema: z.object({ name: z.string() }),
  outputSchema: z.object({ greeting: z.string() }),
  handler: ({ name }) => ({ greeting: `Hello ${name}!` }),
})

export default createMcpHandler({
  name: 'private-tools',
  auth: { tokens: [process.env.MCP_PRIVATE_TOKEN!] },
  tools: [greet],
})
```

Manual handlers accept explicit tool, resource, and prompt collections, including readonly arrays. They also accept live authentication callbacks and `onToolCall`. Automatic discovery does not add definitions to this route; include each definition deliberately.

`createMcpHandler` from `@nuxtjs/mcp-toolkit/server` is the Nuxt adapter. Standalone Nitro 3 uses the helper from `nitro-mcp-toolkit` directly. Both expose `fetch`, `definitions`, and `notify`.

## Retire the old options

`middleware`, `browserRedirect`, `experimental_codeMode`, dynamic definition resolvers, `defaultHandler`, and SDK server-creation hooks are removed. Use ordinary Nuxt middleware, `websiteUrl`, endpoint configuration, explicit composition, and the shared engine's extension API.
