## Validate input formats

Use Zod's format validation, then return a plain object matching the output schema:

```ts [server/mcp/tools/validate-input.ts]
import { z } from 'zod'
import { defineMcpTool } from '@nuxtjs/mcp-toolkit/server'

export default defineMcpTool({
  description: 'Validate an email address or URL',
  annotations: { readOnlyHint: true, openWorldHint: false },
  inputSchema: z.object({
    value: z.string(),
    format: z.enum(['email', 'url']),
  }),
  outputSchema: z.object({ isValid: z.boolean() }),
  handler: ({ value, format }) => ({
    isValid: (format === 'email' ? z.email() : z.url()).safeParse(value).success,
  }),
})
```

A valid tool call can return `{ isValid: false }`; invalid arguments are rejected before the handler runs. Each structured result also has a JSON text fallback for clients.

## Generate a slug

Defaults in the input schema are applied before the callback:

```ts [server/mcp/tools/generate-slug.ts]
import { z } from 'zod'
import { defineMcpTool } from '@nuxtjs/mcp-toolkit/server'

export default defineMcpTool({
  description: 'Generate a URL-friendly slug from a title',
  annotations: { readOnlyHint: true, openWorldHint: false },
  inputSchema: z.object({
    title: z.string(),
    separator: z.enum(['-', '_']).default('-'),
  }),
  outputSchema: z.object({ slug: z.string() }),
  handler: ({ title, separator }) => ({
    slug: title.toLowerCase()
      .normalize('NFD')
      .replace(/[\u0300-\u036f]/g, '')
      .replace(/[^a-z0-9\s_-]/g, '')
      .trim()
      .replace(/[\s_-]+/g, separator),
  }),
})
```

Return `{ slug }` directly. A tool with `outputSchema` treats plain objects as schema data; use [`toolResult()`](/tools/schema-handler#return-a-protocol-envelope-explicitly) only when supplying a protocol envelope yourself.

## Convert JSON and YAML

This example requires the `yaml` package in your application. Parser failures become `isError` tool results:

```ts [server/mcp/tools/convert-format.ts]
import { z } from 'zod'
import { parse, stringify } from 'yaml'
import { defineMcpTool } from '@nuxtjs/mcp-toolkit/server'

export default defineMcpTool({
  description: 'Convert a document between JSON and YAML',
  annotations: { readOnlyHint: true, openWorldHint: false },
  inputSchema: z.object({
    content: z.string(),
    from: z.enum(['json', 'yaml']),
    to: z.enum(['json', 'yaml']),
  }),
  outputSchema: z.object({ content: z.string() }),
  handler: ({ content, from, to }) => {
    const data: unknown = from === 'json' ? JSON.parse(content) : parse(content)
    return { content: to === 'json' ? JSON.stringify(data, null, 2) : stringify(data) }
  },
})
```

## Check a configured service

A health check can take no arguments and still advertise structured output. Set `HEALTHCHECK_URL` to a service your application operates:

```ts [server/mcp/tools/health-check.ts]
import { z } from 'zod'
import { defineMcpTool } from '@nuxtjs/mcp-toolkit/server'

const healthOutput = z.object({
  status: z.enum(['healthy', 'unhealthy']),
  responseTimeMs: z.number(),
  statusCode: z.number().optional(),
})

export default defineMcpTool({
  description: 'Check the configured application service',
  annotations: { readOnlyHint: true, openWorldHint: true },
  outputSchema: healthOutput,
  handler: async (): Promise<z.input<typeof healthOutput>> => {
    const url = process.env.HEALTHCHECK_URL
    if (!url) throw new Error('The health check service is not configured.')
    const start = performance.now()

    try {
      const response = await fetch(url, { method: 'HEAD', signal: AbortSignal.timeout(5000) })
      return {
        status: response.ok ? 'healthy' : 'unhealthy',
        responseTimeMs: performance.now() - start,
        statusCode: response.status,
      }
    }
    catch {
      return { status: 'unhealthy', responseTimeMs: performance.now() - start }
    }
  },
})
```

An unavailable service is a meaningful health result. Missing server configuration is an execution error. There is no empty input schema or placeholder argument.
