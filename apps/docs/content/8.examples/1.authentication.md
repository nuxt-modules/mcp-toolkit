## Choose the endpoint credential

For user authorization, configure an OAuth resource server. For a controlled service integration, a static bearer token can protect an entire endpoint. API keys and OAuth access tokens have different issuance and discovery flows; a browser session alone does not establish MCP authorization.

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@nuxtjs/mcp-toolkit'],
  mcp: {
    oauth: {
      resource: 'https://example.com/mcp',
      authorizationServers: ['https://auth.example.com'],
      jwt: { jwks: 'https://auth.example.com/.well-known/jwks.json' },
      scopesSupported: ['profile:read'],
    },
  },
})
```
```ts [server/mcp/tools/whoami.ts]
import { z } from 'zod'
import { defineMcpTool } from '@nuxtjs/mcp-toolkit/server'

export default defineMcpTool({
  description: 'Read the verified user identifier',
  scopes: ['profile:read'],
  annotations: { readOnlyHint: true, openWorldHint: false },
  outputSchema: z.object({ userId: z.string() }),
  handler: (event) => {
    const userId = event.context.oauth?.sub
    if (!userId) throw new Error('A verified user is required.')
    return { userId }
  },
})
```

See [the OAuth guide](/getting-started/oauth) for provider connectors, metadata paths, audience validation, and per-endpoint configuration.

## Use a static service token

```ts [nuxt.config.ts]
const token = process.env.MCP_TOKEN
if (!token) throw new Error('MCP_TOKEN is required.')

export default defineNuxtConfig({
  modules: ['@nuxtjs/mcp-toolkit'],
  mcp: { auth: { tokens: [token] } },
})
```

Configure the client to send `Authorization: Bearer <token>` on its requests. Do not embed the credential in public documentation, a badge, a deeplink, or a tool argument. A static credential does not populate a user-specific OAuth subject or scopes by itself.

## Compose OAuth manually

Prefer configured `mcp.oauth` for discovered JWT endpoints. Manual composition is useful when a route needs a live verifier or an explicit definition collection. The following JWT example also shows the metadata route that manual composition must mount.

```ts [server/utils/mcp-oauth.ts]
import { createMcpOAuth } from '@nuxtjs/mcp-toolkit/server'

export const oauth = createMcpOAuth({
  resource: 'https://example.com/private-mcp',
  authorizationServers: ['https://auth.example.com'],
  jwt: { jwks: 'https://auth.example.com/.well-known/jwks.json' },
  scopesSupported: ['profile:read'],
})
```
```ts [server/mcp-private/tools/whoami.ts]
import { z } from 'zod'
import { defineMcpTool } from '@nuxtjs/mcp-toolkit/server'

export default defineMcpTool({
  name: 'whoami',
  description: 'Read the verified user identifier',
  scopes: ['profile:read'],
  annotations: { readOnlyHint: true, openWorldHint: false },
  outputSchema: z.object({ userId: z.string() }),
  handler: (event) => {
    const userId = event.context.oauth?.sub
    if (!userId) throw new Error('A verified user is required.')
    return { userId }
  },
})
```
```ts [server/routes/private-mcp.ts]
import { createMcpHandler } from '@nuxtjs/mcp-toolkit/server'
import { oauth } from '../utils/mcp-oauth'
import whoami from '../mcp-private/tools/whoami'

export default createMcpHandler({
  name: 'private-mcp',
  auth: oauth.auth,
  tools: [whoami],
})
```
```ts [server/routes/.well-known/oauth-protected-resource/private-mcp.ts]
import { defineEventHandler } from 'nuxt/server'
import { oauth } from '../../../utils/mcp-oauth'

const headers = {
  'access-control-allow-origin': '*',
  'access-control-allow-methods': 'GET, OPTIONS',
  'access-control-allow-headers': '*',
}

export default defineEventHandler((event) => {
  if (event.req.method === 'OPTIONS') return new Response(null, { status: 204, headers })
  if (event.req.method !== 'GET') {
    return new Response(null, { status: 405, headers: { ...headers, allow: 'GET, OPTIONS' } })
  }
  return Response.json(oauth.metadata, { headers })
})
```

`oauth.metadataPath` identifies this metadata URL. Use the public resource origin consistently; it is also carried in authentication challenges. The configured module mounts metadata through its native adapter automatically, while a manual route owns its host HTTP integration.

For opaque tokens, replace JWT verification with `createMcpOAuth({ verify })` backed by your provider's resource-aware verifier. Populate verified `event.context.oauth` claims for identity/scopes. Do not accept a token merely because it exists or belongs to another API.

Test no credential, valid tokens, wrong issuer/audience, expiry, missing scopes, and concurrent users. Full provider login, client registration, consent, and refresh require provider/client tests as part of beta validation.
